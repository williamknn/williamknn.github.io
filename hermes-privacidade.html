Hermes Personal: Política de Privacidade

Última atualização: 03/11/2026

Hermes Personal é um assistente de uso pessoal e privado, operado por William Kennedy (will.lindemann@gmail.com). Não é oferecido ao público.

Dados acessados

Com autorização explícita do próprio titular da conta, o app lê Gmail, Google Agenda, Drive, Docs, Planilhas e Contatos para gerar resumos e lembretes pessoais.

Uso e armazenamento

  • Os dados são processados apenas no computador do titular e usados somente para o próprio titular.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.
  • O uso de dados recebidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
